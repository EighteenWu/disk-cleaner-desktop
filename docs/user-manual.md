# DiskClean 操作手册（0.2.0）

面向 Windows 10/11。本手册说明日常用法；自定义 YAML 语法见 [custom-rules.md](custom-rules.md)。

## 1. 安装与启动

1. 运行 `DiskClean_0.2.0_x64-setup.exe`（或对应 MSI）。
2. 全盘分析若要用 NTFS `$MFT` 加速，请以管理员启动（标题栏可「以管理员重启」）。
3. 不需要账号。AI 为可选功能，使用自己的供应商 Key。

## 2. 扫描

侧栏选择盘符，再选模式：

| 模式 | 做什么 |
| --- | --- |
| 快速扫描 | 只扫回收站和已启用规则里的路径，适合日常清理。 |
| 全盘分析 | 遍历选中卷（优先 `$MFT`），空间分析里能看到目录占用；也是 AI 对话的前提。 |

清理档位（低 / 中 / 高）只决定**这次清理用哪些已启用规则**，以及默认勾选范围。它不决定是否遍历整盘。

空规则库时，快速扫描几乎只能看到回收站。可点「使用推荐规则」导入官方包，再扫。

## 3. 查看结果并清理

1. 「清理」列表按来源分组。推荐项可能默认勾选；谨慎项和需确认项默认不勾。
2. 全盘分析可切到「空间」看占用最大的目录；标成受保护 / 仅分析的不要当垃圾删。
3. 勾选后点「预览并清理」。默认进回收站。永久删除必须单独勾选。
4. 可暂停或取消。完成后看日志。

不要勾选：Windows 系统目录、Program Files 安装树、文档/桌面、Cookie、登录数据、聊天数据库。

## 4. 规则

打开「规则」：

- **推荐规则**：一点导入。不会开机自动启用。
- **本地规则库**：只有「已批准 / 已启用」的记录会进扫描。可停用、再启用、编辑 YAML、删除。删除后列表里不再出现，不能恢复。
- **订阅 / Winapp2**：高级区。订阅走 HTTPS；Winapp2 只导入安全子集。

## 5. AI 生成规则

AI **不会删文件**。它只根据本机扫描结果写规则，你确认后再启用。

1. 先完成一次**全盘分析**。
2. 规则对话框里选择厂商、填写 API Key、检测并保存。Key 只存在本机凭据库，不要发给任何人，也不要写进仓库或截图。
3. 在对话里直接发送（可不打字）。软件会把占空间最大的一批**目录**发给模型（路径做成 `%LOCALAPPDATA%` 这类模板，外加大小），不是每个文件。
4. 回复应按 **大小、路径、说明、影响** 列出：建议可清 / 要确认 / 不要动。
5. 可用对话继续改范围。点「通过」才生成 YAML、本地编译、写入规则库并启用。全库只保留一条 AI 规则，再次通过会替换。
6. 再扫一次，在清理列表里勾选后预览执行。

没有全盘库存时，对话仍可用候选项摘要，但覆盖会变窄。

## 6. 自动化（可选）

可配置登录后或定时扫描。自动化只用已启用且校验通过的规则，不会在后台调用 AI，也不会自动批准草稿。失败会停在安全侧并写本地报告。

## 7. 隐私与密钥

| 内容 | 位置 |
| --- | --- |
| API Key | Windows 凭据管理器，应用命名空间 + 配置 ID |
| 供应商非秘密配置 | 应用数据目录（无 Key） |
| 规则库 | 应用数据目录 |
| 全盘库存 SQLite | 本机缓存，随扫描会话删除，不进 Git、不发给模型全文 |

不要提交或分享：`.env`、真实 Key、凭据导出、`scan-inventory/*.sqlite3`、本机规则库里带私人路径的草稿。

## 8. 卸载

用系统「应用和功能」卸载安装包。卸载后凭据和规则库是否保留取决于安装器设置；需要时可手动删除 `%APPDATA%\com.cleandeck.desktop` 与 `%LOCALAPPDATA%\com.cleandeck.desktop`。
